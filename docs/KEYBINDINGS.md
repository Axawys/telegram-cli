# Клавиши и команды

Раскладка задаётся в `src/telega/vim/keymap.py` (`DEFAULT_KEYMAP`), описания для экрана `?` — в `ACTION_HELP` там же. Тест `test_every_action_has_help` не даст забыть описание.

Нотация как в vim: `<C-d>` — Ctrl+D, `<CR>` — Enter, `<Esc>`, `<Tab>`.
Счётчик перед командой повторяет её: `5j`, `3<C-d>`. `5gg` и `5G` переходят на пятую строку.

## NORMAL — везде

| Клавиши | Действие |
|---|---|
| `:` | командная строка |
| `/` | в чатах — живой фильтр по названию или @username; в сообщениях — поиск по загруженным |
| `n` / `N` | следующее / предыдущее совпадение поиска (в сообщениях) |
| `?` | справка |
| `Tab` | переключить панель |
| `C-h` / `C-l` | к чатам / к сообщениям |
| `C-v` | открыть поле ввода и вставить буфер обмена: картинку — вложением, текст — текстом |
| `C-n` | скрыть / показать список чатов. Скрытый список выдвигается по `h` / `Tab` / `C-h` и прячется снова после открытия чата или возврата к сообщениям |
| `i`, `a` | написать сообщение (INSERT) |
| `ZZ`, `ZQ` | выход |
| `Esc` | сбросить фильтр и поиск |

## Лидер `Space` (как в LazyVim)

После `Space` внизу открывается окно с доступными продолжениями (which-key). Пункты с `+` — группы: следующая клавиша откроет их содержимое. `Backspace` — шаг назад, `Esc` — отмена. Для остальных префиксов (`g`, `d`, `y`, `Z`) то же окно появляется, если подождать полсекунды.

| Клавиши | Действие |
|---|---|
| `Space Space` | найти чат: фильтр списка чатов |
| `Space e` | скрыть / показать список чатов (то же, что `C-n`); при показе фокус переходит на список, курсор — на текущий чат |
| `Space /` | поиск |
| `Space :` | командная строка |
| `Space ?` | справка |
| `Space t` | сменить тему: окно со списком, `j` / `k` сразу показывают тему, `Enter` — оставить (запоминается в `config.toml`), `Esc` — вернуть прежнюю |
| `Space w w` / `w h` / `w l` | переключить панель / к чатам / к сообщениям |
| `Space p c` / `p m` | профиль текущего чата / свой профиль |
| `Space r` | ответить на выделенное сообщение (то же, что `r`) |
| `Space b` / `Space f` | назад / вперёд по переходам к исходным сообщениям (как `C-o` / `C-i` в vim). Переходы копятся цепочкой без ограничения глубины, свои у каждого чата; новый переход после «назад» обрывает ветку «вперёд» |
| `Space l` … | реакция на выделенное сообщение — группа в меню, следующая клавиша выбирает реакцию. Повторный выбор своей реакции снимает её |
| `Space l l` / `d` / `h` / `f` / `c` | like / dislike / heart / fire / clown |
| `Space l p` / `t` / `g` / `r` / `s` | party / thinking / grin / rofl / cry |
| `Space l e` / `o` / `w` / `1` | eyes / ok / mind blown / hundred |
| `Space l /` | все реакции: окно с поиском по названию (`clo` → clown), `↑`/`↓` или `C-n`/`C-p`, `Enter` — поставить |
| `Space l x` | снять свою реакцию |
| `Space o` | перейти к исходному сообщению, на которое отвечает выделенное (то же, что `gr`); если оно старше загруженного, история подгружается |
| `Space R c` / `R m` | перезагрузить чаты / сообщения |
| `Space q q` | выход |

Названия групп задаются в `KEY_GROUPS` (`src/telega/vim/keymap.py`).

## NORMAL — список чатов

| Клавиши | Действие |
|---|---|
| `j` `k` `↓` `↑` | вниз / вверх |
| `gg` / `G` | первый / последний |
| `C-d` / `C-u`, `C-f` / `C-b` | пол-экрана / экран |
| `l`, `o`, `Enter`, `→` | открыть чат |
| `K`, `gp` | профиль выбранного чата |
| `R` | перезагрузить список |

## NORMAL — сообщения

| Клавиши | Действие |
|---|---|
| `j` `k` | следующее / предыдущее сообщение; у верхнего края подгружается история |
| `gg` / `G` | первое загруженное / последнее |
| `C-d` / `C-u`, `C-f` / `C-b` | прокрутка |
| `h`, `←` | к списку чатов |
| `r` | ответить |
| `e` | редактировать своё |
| `dd` | удалить (с подтверждением `y` / `n`) |
| `yy` | скопировать текст (wl-copy, иначе OSC 52) |
| `K`, `gp` | профиль автора (для постов — канала) с аватаркой |
| `gP` | профиль текущего чата |
| `o`, `Enter` | открыть картинку на весь экран |
| `gr` | перейти к сообщению, на которое ответили (при необходимости подгружает историю) |
| `C-o` | назад по переходам `gr` / `Space o`: к сообщению, с которого перешли; `3C-o` — на 3 шага |
| `R` | перезагрузить сообщения |

## INSERT (поле ввода)

| Клавиши | Действие |
|---|---|
| `Enter` | отправить (при редактировании — сохранить) |
| `Shift+Enter`, `Alt+Enter`, `C-j` | новая строка |
| `Esc` | в NORMAL; отменяет ответ, редактирование и убирает вложение |
| `Ctrl+V` | вставить из системного буфера (wl-paste, на X11 — xclip): картинка (скриншот, «копировать изображение», скопированный файл) прикрепляется с превью над полем ввода, текст вставляется. `Enter` отправляет фото, набранный текст становится подписью; можно и без подписи. Повторный `Ctrl+V` заменяет картинку |
| `@` + буквы | подсказка участников |
| `Tab` / `C-n` / `↓` | следующий кандидат (если подсказка открыта) |
| `S-Tab` / `C-p` / `↑` | предыдущий кандидат |
| `Enter` | выбрать кандидата (если подсказка открыта) |

Остальное — стандартное редактирование `TextArea` Textual: стрелки, `C-a` / `C-e`, `C-w`, `C-u`, выделение Shift+стрелки.

## Модальные окна (профиль, картинка, справка)

`q` / `Esc` — закрыть, `j` / `k` / `C-d` / `C-u` / `g` / `G` — прокрутка. В подтверждении: `y` / `Enter` — да, `n` / `Esc` / `q` — нет.

## Первый запуск и вход

| Экран | Клавиши |
|---|---|
| настройка API | `Enter` — к следующему полю или сохранить; `Tab` — между полями; `Ctrl+O` — открыть my.telegram.org |
| вход | `Enter` — далее; `Ctrl+E` — изменить api_id / api_hash |
| везде | `Ctrl+Q` — выход |

## Команды (`:`)

| Команда | Действие |
|---|---|
| `:q`, `:quit`, `:qa`, `:wq`, `:x` | выход |
| `:open <текст>`, `:o`, `:b`, `:chat` | открыть первый чат, где название содержит текст или username совпадает |
| `:profile` | профиль текущего чата |
| `:profile me` | свой профиль |
| `:read` | отметить чат прочитанным |
| `:reload`, `:e` | перезагрузить чаты и сообщения |
| `:sidebar [on\|off\|toggle]`, `:sb` | показать / скрыть список чатов (без аргумента — переключить) |
| `:theme [имя]`, `:colo` | сменить тему: `cold`, `warm`, `vivid`, `pastel`, `matte` (тёмные), `light`, `bright` (светлые); без имени — окно выбора |
| `:react [название]` | реакция на выделенное сообщение по названию (`:react clown`); повторно — снять; без названия — окно выбора |
| `:help`, `:h` | справка |
| `:noh` | сбросить поиск и фильтр |
| `:<N>` | перейти на строку N в активной панели |

В командной строке `↑` / `↓` листают историю, `Esc` или Backspace на пустой строке закрывают её.
