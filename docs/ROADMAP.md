## Известные ограничения

- **Sixel мерцает** при прокрутке ленты с картинками. Это особенность того, как textual-image встраивает sixel в рендер Textual. В kitty (TGP) проблемы нет. Возможное решение — рисовать картинки только у сообщений в видимой области.
- История не кэшируется локально: каждое открытие чата делает запрос к серверу.
- `MessagesDeletedEvent` для личных чатов и обычных групп приходит без `chat_id`, поэтому id ищутся в текущем открытом чате. Коллизии id между чатами теоретически возможны.
- Подключение ждёт не больше 45 с, каждый шаг входа — не больше 60 с. После этого показывается ошибка с подсказками про VPN, `r` — повторить.
- Список чатов ограничен `dialogs_limit` (100) и пока не подгружается при прокрутке.
- Картинки-документы больше 8 МБ скачиваются как превью, а не оригинал.
- В каналах, где нельзя писать, отправка вернёт ошибку сервера в статусной строке. Права заранее не проверяются.
